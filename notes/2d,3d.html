Quick Reference — All Rules

arr[r, c]
2D single element. Row first, col second.
arr[r, :]
Full row r. ":" = all columns.
arr[:, c]
Full column c. ":" = all rows.
arr[r1:r2, c1:c2]
Sub-matrix. Stop index excluded.
arr[l, r, c]
3D single element. Layer → row → col.
arr[l]
Full 2D layer l from 3D array.
arr[:, r, :]
Row r from every layer in 3D.
arr[-1]
Last element/row/layer. Works in all dims.
Golden rule: ":" always means "give me everything in this dimension." This one rule works in 2D, 3D, 4D — any number of dimensions.
