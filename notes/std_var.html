Standard Deviation & Variance

Formulas, definitions, what they tell you, and how they're used in Machine Learning

📏

Standard Deviation np.std()

Measures the average distance of each data point from the mean. Tells you how spread out your data is — in the same units as the data.

Formula
σ = √[ Σ(xᵢ − μ)² / N ] where: μ = mean of the data xᵢ = each value N = total number of values
Step-by-step
  1. Find the mean (μ) of all values
  2. Subtract mean from each value → (xᵢ − μ)
  3. Square each difference → (xᵢ − μ)²
  4. Average the squares → divide by N
  5. Take the square root → √(result)
📐

Variance np.var()

Measures the average squared distance of each point from the mean. It is Standard Deviation squared — in squared units, so harder to interpret directly.

Formula
σ² = Σ(xᵢ − μ)² / N where: μ = mean of the data xᵢ = each value N = total number of values
Key relationship
  1. Variance = (Standard Deviation)²
  2. Std = √Variance — just take the root
  3. Same steps 1–4 as std, skip the √ root
  4. Units: if data is in kg, variance is in kg²
  5. Std is in kg — same unit as original data
What information do they give you?

📏 From np.std() you learn…

  • How far data points typically stray from the mean
  • Low std → data is tightly clustered (consistent)
  • High std → data is widely spread (high variation)
  • Whether features are on similar scales or very different
  • If a new value is unusual (e.g. >3σ from mean = outlier)
  • The "noise level" in your dataset

📐 From np.var() you learn…

  • The mathematical spread — used in equations that need σ²
  • Low var → values don't deviate much from mean
  • High var → large fluctuations in the data
  • Direction of spread (unlike std, var has additive properties)
  • How much a model's predictions fluctuate (model variance)
  • Foundation for covariance and PCA calculations

🔢 Dry run — array = [2, 4, 6, 8, 10]

np.std([2, 4, 6, 8, 10])
mean (μ)    = (2+4+6+8+10)/5 = 6

differences  = [2-6, 4-6, 6-6, 8-6, 10-6]
             = [-4, -2, 0, 2, 4]

squared      = [16, 4, 0, 4, 16]

average (σ²) = (16+4+0+4+16)/5 = 8

std (σ)      = √8 = 2.83

→ values are on avg 2.83 units from mean
np.var([2, 4, 6, 8, 10])
mean (μ)    = (2+4+6+8+10)/5 = 6

differences  = [2-6, 4-6, 6-6, 8-6, 10-6]
             = [-4, -2, 0, 2, 4]

squared      = [16, 4, 0, 4, 16]

average (σ²) = (16+4+0+4+16)/5 = 8

variance     = 8  (no square root step!)

→ std = √8 = 2.83 confirms the link

⚖️ Key difference — when to use which?

Use np.std() when…

You want a human-readable, interpretable measure of spread. Same unit as your data — easy to understand and report.

Use np.var() when…

You need it in a formula (e.g. Batch Norm, PCA, Gaussian equations). Variance has nice mathematical properties like additivity.

🤖 Uses in Machine Learning
std + var

Batch Normalization

Normalize layer inputs to zero mean and unit std. Stabilizes training and speeds up convergence.

x̂ = (x − μ) / (σ + ε)
std

Feature Scaling / Z-score

Scale features so each has mean=0, std=1. Required for SVM, KNN, logistic regression.

z = (x − mean) / std
var

PCA (Principal Component Analysis)

Covariance matrix is built from variance. PCA finds directions of maximum variance to reduce dimensions.

C = np.cov(X.T)
std

Outlier / Anomaly Detection

Data point more than 2–3 std from the mean is flagged as an anomaly. Common in data cleaning pipelines.

flag = abs(x − μ) > 3σ
var

Bias–Variance Tradeoff

Model variance = how much predictions change with different training data. High var → overfitting.

Error = Bias² + Variance
std + var

Weight Initialization

Xavier / He initialization sets weights using std based on layer size to prevent vanishing/exploding gradients.

w ~ N(0, √(2/n))
std

Loss Stability Monitoring

Track std of loss across batches. High std means unstable training — lower learning rate or add regularization.

np.std(losses[-100:])
var

Gaussian / Probabilistic Models

Gaussian distributions are defined by mean and variance. Used in VAEs, Gaussian Naive Bayes, GPs.

N(μ, σ²)
std

Data Augmentation Noise

Add Gaussian noise with a chosen std to training images/signals to improve model robustness.

x + np.random.normal(0, σ)
Remember:  Variance = Std²  ·  Std = √Variance  ·  Both measure spread, Std is more interpretable, Var is more math-friendly
